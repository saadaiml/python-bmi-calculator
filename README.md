# Python BMI Calculator

This is my first Python mini project, built while learning Python fundamentals.

## Features
- Calculates Body Mass Index (BMI)
- Supports height in meters, centimeters, and feet
- Automatically converts height to meters
- Displays BMI category

## Concepts Used
- Variables
- User Input
- Math Operations
- if, elif, else
